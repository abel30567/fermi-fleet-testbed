# fermi-fleet-testbed

Sacrificial repository for [Fermi](https://github.com/abel30567/fermi-mcp) cloud-agent
fleet verification. Cloud agents clone this repo, make small changes on branches, and
open PRs with proof (test output). Run `npm test` (Node 20+, zero deps).

PRs here are opened by autonomous agents as part of golden-path testing; expect churn.
